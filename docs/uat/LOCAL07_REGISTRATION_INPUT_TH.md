# HorPlus LOCAL-07 — คู่มือข้อมูลสำหรับทดสอบการลงทะเบียนหอพักใหม่ (Registration Input Cheat Sheet)

> **วัตถุประสงค์:** เอกสารนี้รวบรวมค่าข้อมูลตัวอย่าง (Deterministic & Memorable Values) สำหรับให้ **Product Owner** ใช้คัดลอกและกรอกลงในหน้าจอ Onboarding Wizard จริง (`/owner/register`) เพื่อทดสอบการทำงานของฟอร์มครบทุกขั้นตอน ตั้งแต่ Frontend Form -> Request Payload -> Backend Provisioning Service -> PostgreSQL Persistence

---

## 📌 สรุปขั้นตอนการทดสอบ (Quick Guide)

1. รันคำสั่งเปิดหน้า Onboarding:
   ```bash
   npm run uat:open:register
   # หรือ: npm run uat:open -- registration-owner
   ```
2. เบราว์เซอร์จะเปิดที่หน้า `http://127.0.0.1:5173/owner/register` โดยอัตโนมัติ
3. คัดลอกค่าจากตารางด้านล่างนี้กรอกลงในแต่ละขั้นตอน (ขั้นตอนที่ 1 ถึง 6)
4. เมื่อกดยืนยันในขั้นตอนที่ 6 ระบบจะบันทึกข้อมูลและนำทางเข้าสู่หน้าแดชบอร์ดเจ้าของหอพัก (`/owner/dashboard`) ทันที
