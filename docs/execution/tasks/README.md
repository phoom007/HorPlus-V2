# Execution Tasks

ทำตามเลขเรียงจาก `TASK-001` ถึง `TASK-018`

ทุกไฟล์มีโครงสร้างเหมือนกัน:

1. Prerequisite และเหตุผลที่ต้องทำก่อน
2. ขอบเขต/สิ่งที่ห้ามทำ
3. ขั้นตอน implementation
4. Test matrix และ acceptance criteria
5. หลักฐาน handoff และ Task ถัดไป

ถ้า Task ปัจจุบันไม่ผ่าน ให้ทำซ้ำ Task เดิมและอัปเดต defect ห้ามข้ามเลข
